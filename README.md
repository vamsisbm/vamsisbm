# Hi, I'm Vamsi Marella

**Senior Cloud Operations Engineer | Cloud Governance & Platform Engineering | AWS & GCP**

I build the tooling, guardrails, and automation that make cloud infrastructure easier to operate. I have **9+ years in infrastructure**, including five years at **Motorola Solutions**, working across multi-account AWS environments and GCP.

My strongest areas are **Terraform adoption, IAM and cloud governance, inventory automation, and cost attribution**. I lead a five-person cloud operations team and mentor engineers on infrastructure as code.

## What I bring to cloud platforms

- **Infrastructure as code:** Led the migration of an unmanaged AWS estate to Terraform, building dependency-aware imports, dry-run coverage reports, and drift classification. Developed reusable modules for EC2, S3, and RDS.
- **Governance as code:** Wrote cloud policy standards and implemented guardrails with Cloud Custodian, AWS SCPs, and GCP organization policies, supported by a clear exception process.
- **Cloud inventory:** Built Python/boto3 collectors across 15 AWS accounts, 17 services, and 8 regions, with credential refresh for long-running jobs and ServiceNow CMDB integration.
- **FinOps:** Built resource-level cost attribution with AWS Cost & Usage Report and Athena, including ownership mapping and team-level trends, supporting a programme that reduced AWS spend by about 30% in a year.
- **Secure delivery:** Migrated pipelines from Jenkins to GitHub Actions with AWS OIDC federation, replacing long-lived access keys.
